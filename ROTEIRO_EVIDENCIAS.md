# Roteiro de evidências para o relatório

Substitua os marcadores do relatório pelas imagens abaixo após publicar o repositório.

1. **Arquivos do repositório** - tela inicial do repositório mostrando `index.html`, `tests`, `.github` e `README.md`.
2. **Workflow implementado** - arquivo `.github/workflows/cicd.yml` aberto no GitHub.
3. **Execução com falha** - aba Actions com o job `Integração contínua` em vermelho e o log indicando ausência da meta description.
4. **Execução com sucesso** - aba Actions mostrando os jobs `Integração contínua` e `Entrega contínua` em verde.
5. **Log da validação** - etapa `Executar validação automatizada` aberta, exibindo `VALIDAÇÃO APROVADA`.
6. **Deploy** - job `Entrega contínua` aberto com a URL do ambiente `github-pages`.
7. **Aplicação publicada** - site aberto na URL pública do GitHub Pages.

Cada print deve mostrar a barra de endereço quando ela ajudar a confirmar a origem da evidência.
